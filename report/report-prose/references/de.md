# report-prose: German

Load this file when the report has `lang: de`. The rules in `SKILL.md` apply unchanged; this file gives their German connectives and Before/After pairs.

**Connectives.** `weil`, `deshalb`, `daher`, `aber`, `obwohl`, `wenn … dann`. Recap openers the build lints at a section's end: `Also …`, `Damit …`. Figure narration it lints: "Die Tabelle zeigt …", "Das Diagramm listet …".

**Notes.** Evidence notes render under the label "Belege".

1. **Argue the answer.**
   - Before: "Es gibt drei Optionen: Siebdruck, DTF-Transfers und eine eigene Presse."
   - After: "Fertige DTF-Transfers passen am besten, weil der Verein nur zehnmal im Jahr druckt. Deshalb braucht er keine eigene Maschine."
4. **The reader's word first.**
   - Before: "`validate_rows` verwirft Zeilen mit `status` `pending_review`."
   - After: "Die Importprüfung (`validate_rows`) verwirft Zeilen, die noch auf Freigabe warten (`pending_review`)."
9. **Explain before you show.**
   - Before: "Die Tabelle zeigt alle fehlgeschlagenen Zeilen." Then the table, then "Damit verursacht das Datumsformat die meisten Fehler."
   - After: "Das Datumsformat verursacht die meisten Fehler: Die Spalte Datum unten zeigt es." Then the table.
13. **Active voice, present tense.**
   - Before: "Der Lauf wird vom Planer gestoppt, wenn der Import fehlschlägt."
   - After: "Wenn der Import fehlschlägt, stoppt der Planer den Lauf."
15. **State a number once.**
   - Before: "37 Zeilen schlugen fehl." … "Von den 37 Zeilen haben die meisten ein falsches Datum."
   - After: "37 Zeilen schlugen fehl." … "Die meisten davon haben ein falsches Datum."
